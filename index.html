Interactive Navigation Visualisation for 100 Movie Objects

Collection Overview

This prototype demonstrates a visual navigation system for 100 movie objects. Users can move between an overview, genre clusters, timeline navigation, country-based navigation, density view, and individual movie detail pages. This supports selection, movement between objects, and group identification.
